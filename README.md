## Laboratório de Programação (2º semestre)

Pasta atual: [`2 semestre/Lab de programação/`](./2%20semestre/Lab%20de%20programa%C3%A7%C3%A3o)

Listas e trabalhos em C (entrada, validação, menus, cálculos).

### Como compilar um exercício

```bash
gcc arquivo.c -o app -lm
./app
```

`-lm` entra quando o programa usa `math.h` (`sqrt`, `pow`, `ceil`, `floor`).

## Observação

Pastas ainda usam nomes com espaço (como vieram do computador). A ideia é ir padronizando sem quebrar o histórico de uma vez.
